## 为什么要重构

旧的网站基于 Vue 3 + Vuetify 3，功能完整但品牌识别度弱。这次重构选择了 Next.js + Tailwind CSS + shadcn/ui，希望能呈现更好的视觉设计和阅读体验。

## 技术选型

- 框架：Next.js 16 (App Router)
- 样式：Tailwind CSS v4
- 组件：shadcn/ui
- 内容：MDX
- 动画：Framer Motion

## 设计理念

采用品牌工作室风格，融合极简排版基因。暖色中性色调，克制的微交互，注重信息传达效率。
